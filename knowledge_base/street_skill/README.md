# Street Skill runtime bundle

This directory is generated by `scripts/sync_street_skill.py`.

It contains only structured rules, knowledge cards, source metadata and
terminology distilled from the `design-human-centered-streets` Skill. Source
PDFs and copyrighted figure images are intentionally excluded.

Runtime precedence is:

1. Current Taiwan requirements
2. Taiwan national guidance
3. International manuals as comparative methods

Generated street images are concept visualizations. They do not replace field
measurement, authority review, detailed design, or a compliance determination.
